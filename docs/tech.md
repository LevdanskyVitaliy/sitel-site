# Техническая документация

## 1. Стек и принципы

- **Чистый статический MPA**: HTML5 + CSS + ванильный JavaScript. Никаких сборщиков, фреймворков, npm-зависимостей.
- Осознанное правило из ревью: **без тяжёлых эффектов** — никаких IntersectionObserver, shimmer, pulse-glow, бесконечных анимаций (комментарий в шапке `js/main.js`).
- Шрифты: Inter (400–800) + Merriweather (700, 900) через **Google Fonts CDN** (`<link>` в `<head>` каждой страницы). Папка `/fonts` содержит локальные Inter woff2 (Medium/Regular/SemiBold), но `@font-face` в CSS не описан — см. «Открытые дефекты».
- Favicon — inline SVG (синий квадрат с буквой «S»).

## 3. Архитектура CSS (`css/styles.css`)

Файл организован нумерованными секциями:

| # | Секция | Строки | Содержание |
|---|---|---|---|
| 1 | Базовые настройки и переменные | 1–70 | reset, `:root` токены, типографика, `.container` (max-width 1200px) |
| 2 | Утилиты, кнопки и бэджи | 72–137 | `.btn*`, `.badge*`, `.placeholder-tag`, `.card`, `section`-ритм (64px 0, разделители) |
| 3 | Шапка | 139–182 | fixed header, logo, nav, dropdown, mobile menu |
| 4 | Hero-секции | 184–207 | hero-grid, page-hero, прототип дашборда |
| 5 | Гриды, таблицы, карточки | 208–~298 | features/security grids, compare/spec tables, legal-box, case-карточки, аккордеон, contact-section (тёмная), футер |
| 6 | Адаптив | 371–496 | брейкпоинты 1024 / 768 / 480 px |
| 7 | Доступность | 498–499 | `prefers-reduced-motion: reduce` |

Важно: часть layout-правил сделана **атрибутными селекторами поверх inline-стилей** (например, `div[style*="grid-template-columns:1fr 1fr"]`) — это работает, но хрупко; при рефакторинге выносить inline-гриды в классы.

## 4. JavaScript (`js/main.js` + inline-дубли)

Публичные глобальные функции (вызываются из `onclick` в разметке):

| Функция | Назначение |
|---|---|
| `initHeader` (IIFE) | Тень шапки при `scrollY > 20` (класс `scrolled`) |
| `closeMobile()` | Закрыть мобильное меню |
| `toggleDropdown(id)` | Открыть/закрыть дропдаун «Платформы»; закрытие по клику вне — через делегирование |
| `toggleAccordion(btn)` | Аккордеон; закрывает остальные (по одному открытому), ставит `aria-expanded` |
| `openModal(type)` / `closeModal(type)` | Модалки `#modal-{type}`; блокировка скролла body |
| `handleContactForm(e)` | Отправка формы на `https://api.web3forms.com/submit` (fetch), показ `#form-success`, дисейбл полей |

Плюс: закрытие модалок по overlay-клику и **Escape**, плавный скролл по якорям на `DOMContentLoaded`.

⚠ В `index.html` строки 459–509 продублирован inline `<script>` (частично повторяет `main.js`). Источник правды — `main.js`; inline-дубль в index стоит удалить при первой правке, иначе поведения разъезжаются.

## 5. Форма заявки (contact.html)

- Бэкенд: **Web3Forms** (`action="https://api.web3forms.com/submit"`, POST, скрытые поля `access_key`, `subject`, `from_name`).
- Поля: имя, компания, email, телефон, select «задача» (Речевая аналитика / Умный автозаказ / Документооборот / Несколько задач).
- **Чекбокс согласия на обработку ПД** — обязателен по правилу 152-ФЗ из ревью. Есть.
- JS `handleContactForm` перехватывает submit, шлёт fetch и показывает блок успеха. Перед продакшеном проверить реальный `access_key`.

## 6. Запуск и деплой

```bash
# Локально (из корня Sitel-work):
python3 -m http.server 8000
# → http://localhost:8000
```

Деплой — любой статический хостинг (GitHub Pages, nginx, CDN). Текущий оригинал, судя по ревью, живёт на GitHub Pages (`vixaiia.github.io/Panel`). Пути в разметке относительные, но `/css/styles.css` в `<head>` — абсолютный от корня домена: **при деплое в подкаталог (например, `site.com/sitel/`) стили не подхватятся** — заменить на `css/styles.css` (см. дефекты).

Сборка не требуется. Минификация не настроена (и не обязательна на текущем размере).

## 7. Что учесть при доработках

1. Правки шапки/футера — во всех 9 HTML-файлах (нет шаблонизации). Если изменений будет много — рассмотреть сборку через простые include или вынос в JS-инжект.
2. `index.html` подключает Google Fonts, локальные шрифты в `/fonts` мёртвым грузом.
3. Скрипты подключены частично inline (index), частично через `js/main.js` (остальные страницы — проверить при правках: `grep -n 'main.js' *.html platforms/*.html`).
4. Модалки (`openModal`) объявлены в JS, но используются не на всех страницах — при удалении модалок со страницы функция просто вернёт `undefined`-guard, ничего не сломается.
