# Правила из ревью v1 и статус их выполнения

Источник правил: **«Ревью сайта NeuralCore. Визуальный стиль и подача информации: аудит + отраслевое исследование» (v1, 26.07.2026)** — полный разбор старого одностраничника `vixaiia.github.io/Panel` (NeuralCore = прежнее имя того же продукта) плюс питч-документ «Извлечение — у себя, интеллект — по подключению» (v2, 11.07.2026). Сайт Sitel — результат переделки по этим правилам. Ниже: свод правил → что применено → что осталось.

## 1. Отраслевые закономерности (Часть I ревью) — фундамент переделки

| Правило | Статус на Sitel |
|---|---|
| Светлый корпоративный фон — норма категории (все конкуренты: 3iTech, imot.io, Observe.AI, CallMiner — светлые/синие) | ✅ Применено: светлый фон #F8FAFC, синяя корпоративная палитра, Merriweather-заголовки |
| Доказательство вытеснило обещание | ✅ Частично: вместо «20 лет в Enterprise AI» и фейк-цифр — честные бэджи «ШАБЛОН», «ПРОТОТИП», «НЕ ЗАПОЛНЕНО» |
| Готовая матрица сравнения (РФ-рынок) | ✅ Таблица сравнения Уровень 1 / Уровень 2 на index и architecture |
| «Суверенный AI» — архитектурное утверждение, не слоган | ✅ Целые страницы security.html и architecture.html обосновывают суверенность: слои хранения, обезличивание ПДн, режим аудита для контура Б |
| Многостраничная ИА | ✅ 9 страниц; флагман — на главной; платформы — в подпапке `platforms/` |

## 7. Что из старого сайта сохранять нельзя (антиправила)

Тёмный графит + неоновый градиент cyan→teal, glassmorphism, shimmer-анимации, обещания без доказательств («20 лет в Enterprise AI», «в 8–12 раз» без источника), телефон-заглушка, формы-имитации, ссылки-заглушки `#`, chat-виджет, кегль <12px, весь контент с opacity:0 без noscript.
