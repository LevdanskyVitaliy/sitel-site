## С чего начать

- Изучить сайт как пользователь: открыть `index.html` в браузере или поднять локальный сервер: `python3 -m http.server 8000`
- Правки дизайна: `css/styles.css` (дизайн-токены в `:root`, строки 10–45)
- Правки поведения: `js/main.js` (единый файл на все страницы)
- Контент страниц: правится прямо в HTML каждой страницы (общие шапка и футер продублированы в каждом файле)

## Критический контекст для любых правок

1. **Правки вносятся в рабочую копию `Sitel-work`**, оригинал `/Users/vitaliylevdansky/Desktop/SITEL/Sitel` не трогаем.
