# Дизайн-система

Стиль сознательно выведен из требований ревью v1: **светлый корпоративный язык категории** (речевая аналитика для enterprise-РФ), вместо тёмного неонового AI-стартап-стиля старого сайта.

## 2. Типографика

- **Заголовки — Merriweather (serif, 700/900)**, основной текст — Inter. Сериф в заголовках — осознанный ход «серьёзного корпоративного» регистра, отличающий от безликих AI-сайтов.
- `h1: clamp(1.875rem, 4vw, 3rem)`, `h2: clamp(1.5rem, 3vw, 2.25rem)`, `h3: clamp(1.125rem, 2vw, 1.5rem)`, `h4: 1rem` — всё через `clamp`, кегль адаптивный без брейкпоинтов.
- Мелкий текст: 13–14px в карточках, 12px в подписях метрик — минимум, ниже которого опускаться нельзя (правило ревью: не ниже 12px).

## 3. Компоненты

| Компонент | Классы | Особенности |
|---|---|---|
| Кнопки | `.btn`, `.btn-primary`, `.btn-outline`, `.btn-sm`, `.btn-block` | Primary — сплошной blue-700, hover — blue-900 + сдвиг; Outline — рамка 2px |
| Бэджи | `.badge-blue/-teal/-dark/-amber`, `.badge-template` | Uppercase 11px, letter-spacing .08em; **`.badge-template` — красный пунктирный «ШАБЛОН» для недоказанных утверждений** |
| Плейсхолдеры контактов | `.placeholder-tag`, `.contact-placeholder` | Красный пунктирный тег «НЕ ЗАПОЛНЕНО» в футере |
| Карточки | `.card`, `.card-flat` | Белые, рамка + тень, hover-подъём 2px |
| Таблицы | `.compare-table`, `.spec-table` | ✓ зелёный, ⏳ amber (`.pending`), «—» серый (`.dash`) — для сравнения уровней 1/2 |
| Кейсы | `.case-card-large`, `.case-metric-box` | Двухколоночные карточки, крупные Merriweather-цифры 2.5rem на голубых плитках |
| Аккордеон | `.accordion-*` | Один открытый, `max-height` анимация (лимит 1200px), стрелка-поворот |
| Прототип дашборда | `.proto-*` | Стилизованный мокап интерфейса с бэджем «ПРОТОТИП» — честная маркировка вместо скриншота несуществующего продукта |
| Секции | `section` | Ритм 64px 0, разделитель `border-top`; чередование белых и `.section-blue` |

## 4. Адаптивность

| Брейкпоинт | Что происходит |
|---|---|
| ≤1024px | Промежуточные сжатия гридов |
| ≤768px | Гриды → 1 колонка; навигация скрывается (`.nav-links display:none`), включается burger `.mobile-toggle`; футер **строго 2 колонки**; hero-кнопки на всю ширину |
| ≤480px | Компактнее: padding 16px, h1 1.75rem, футер остаётся 2 колонки |

Особенность: футер намеренно держит 2 колонки даже на телефонах (комментарий «ФУТЕР НА ТЕЛЕФОНАХ — ОСТАЕТСЯ В 2 КОЛОНКИ»).

## 5. Доступность

- `prefers-reduced-motion: reduce` — глобально гасит анимации/переходы (styles.css:498).
- `aria-expanded` на дропдауне и аккордеоне, `aria-label` на burger.
- Модалки закрываются по Esc и клику по overlay.
- Табличные состояния кодируются не только цветом, но и символами (✓ / ⏳ / —).
- Контраст: primary-текст #0F172A на #F8FAFC и синий #1D4ED8 на белом — проходят WCAG AA; мелкий `.text-light` #94A3B8 использовать только для некритичных подписей.

## 6. Чего в дизайне быть не должно (правила ревью)

Тёмный фон как основной, неоновые градиенты cyan→teal, glassmorphism, shimmer-анимации, бесконечные pulse-glow, chat-виджеты поверх контента, шрифт <12px, скрытие контента без `<noscript>`. Всё это было выброшено из старого NeuralCore-сайта и не должно возвращаться.
