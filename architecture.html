АРХИТЕКТУРА

Базовый продукт — у вас навсегда. Расширенная аналитика — по подписке

Граница проходит по техническому шву: распознавание речи работает на обычном процессоре, серьёзная GPU-инфраструктура нужна только большой языковой модели. Три контура развёртывания — вы выбираете, где проходит граница.

МОДЕЛЬ ПРОДУКТА

За независимость платят один раз. За глубину — пока она нужна

БАЗОВЫЙ ПРОДУКТ

Уровень 1 — у вас навсегда

Даже если завтра отключат интернет, а послезавтра закончится подписка — вот что продолжит работать у вас как ни в чём не бывало:

  • → Расшифровка 100% звонков на CPU
  • → Контроль скриптов и комплаенса
  • → Эмоции, метрики, темы обращений
  • → Базовый скоринг операторов
  • → ИИ-голосовой помощник
  • → Дашборды и отчёты в реальном времени
  • → Малая языковая модель для резюме
Железо: обычный сервер, без дорогостоящих GPU для основной нагрузки. Одна видеокарта 24 ГБ для малой модели.
РАСШИРЕННАЯ АНАЛИТИКА

Уровень 2 — по подключению

Большая языковая модель (32+ млрд параметров) подключается как услуга к уже накопленным данным. Объясняет причины, даёт рекомендации, прогнозирует поведение.

  • → Смысловой чек-лист с цитатами-обоснованиями
  • → Диагностика причин ошибок
  • → Рекомендации коучу с таймкодами
  • → Еженедельные дайджесты для руководства
  • → Прогноз оттока клиентов
  • → Самообучение бота из лучших ответов
  • → «Плейбук лучших операторов»
Принципиально: отключение подписки не приводит к потере данных. Очередь вместо потери.

ОБОРУДОВАНИЕ

Требования к железу и GPU

Основной функционал работает без дорогостоящих GPU. Оптимизированные модели не требуют колоссальных вычислительных ресурсов.

«Если STT работает на CPU, а большая модель опциональна — зачем в базовой поставке видеокарта?»

Видеокарта в базовой поставке нужна не для распознавания речи (оно действительно работает на CPU), а для малой языковой модели, которая входит в базовый уровень: краткое резюме каждого звонка, автоматические названия новых тем, простые смысловые проверки для базового скоринга. Она работает полностью у вас, без внешних подключений.

Если эти функции не нужны — конфигурация упрощается до сервера без GPU. Расчёт предоставляется при запросе демо.

⚠ Серверная линейка GPU для продакшена

RTX 4090 — потребительская карта. Лицензионное соглашение NVIDIA не предполагает её использование в дата-центре. Для банков, госсектора и медицины служба ИБ и закупки упрутся в это сразу.

По умолчанию для продакшн-развёртывания мы предлагаем серверную линейку (NVIDIA L40S / A30 или эквивалент) либо отечественные ускорители. Розничная карта 24 ГБ допустима как осознанное решение для пилотов и малых инсталляций — мы показываем расчёт TCO «розничная карта сейчас vs серверная сразу». Выбор фиксируется в спецификации до подписания контракта.

СКОРИНГ

Оценка операторов: детектор и диагност

Базовый скоринг — детектор (находит проблему и показывает где). Расширенный — диагност (объясняет почему и назначает лечение). Детектор у клиента навсегда; диагност — по подключению.
