# Sitel — сайт

Статический многостраничный сайт B2B-продукта Sitel: речевая аналитика on-premise (флагман), умный автозаказ, интеллектуальный документооборот. Без сборки и зависимостей — HTML + CSS + ванильный JS.

> Это **рабочая копия** проекта. Оригинал: `../Sitel` — не редактировать.

## Запуск

```bash
python3 -m http.server 8000
# → http://localhost:8000
```
