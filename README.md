# Sitel — сайт платформы комплексной ИИ-тизации

Статический многостраничный сайт B2B-платформы Sitel: **all-in-one** для задач речевого интеллекта и обработки данных. Ядро — векторная база данных и стек ИИ (ASR, NLU, голосовая биометрия, no-code конструктор бота, Аналитика v2.0); прикладные решения — речевая аналитика, умный автозаказ, интеллектуальный документооборот.

Без сборки и зависимостей: HTML + CSS + ванильный JS.

> Это рабочая копия проекта (итерация 2). Оригинал `../Sitel` — не редактировать.

## Запуск

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Структура

```
index.html                 — главная: hero all-in-one, ядро платформы, модули, контуры
cases.html                 — «Отрасли и бизнес-задачи»: 5 отраслевых решений
architecture.html          — архитектура и оборудование: Уровень 1 / Уровень 2, три контура
security.html              — безопасность и соответствие: 152-ФЗ, слои хранения, аудит
platforms/auto-order.html  — умный автозаказ
platforms/docs.html        — интеллектуальный документооборот
contact.html               — форма заявки (Web3Forms) с чекбоксом согласия
privacy.html               — политика обработки персональных данных по 152-ФЗ
css/ js/ fonts/ logo/ downloads/  — стили, скрипты, шрифты, логотипы, презентация
docs/                      — документация проекта
tools/check_links.py       — аудит внутренних ссылок и баланса тегов
```

## Проверка перед публикацией

```bash
python3 tools/check_links.py   # → PAGES: 8 / All local links OK
```
